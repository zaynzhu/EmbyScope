# macOS 原生预览版

2026-10-21：本版用于体验新首页和原生桌面工作流。采用暖白、浅灰与琥珀色的原生界面，首页将主封面与最近四条观看记录并排展示，窄区域保留主封面并在下方显示完整记录。Mac 优先，网页版继续保留；没有修改现有 NAS、TTD、302 反代或其端口。

## 构建与打开

要求 macOS 14 或以上、Swift 工具链（可使用 Command Line Tools），开发机通过 fnm 安装项目 `.node-version` 指定的 Node 22.22.2。本轮在 Apple Silicon Mac 验证；构建脚本使用本机架构，不生成通用二进制。

在项目根目录执行：

```sh
scripts/test-macos.sh
scripts/build-macos-app.sh
open dist/EmbyScope.app --args --demo
```

应用内附 Node 及其 LICENSE，运行时无需 fnm、Homebrew 或系统 Node。构建检查 Node 不依赖 Homebrew 动态库。产物为 `dist/EmbyScope.app`，采用本机临时签名；不等同于 Apple Developer ID 签名或公证。`scripts/build-macos-dmg.sh` 会构建并校验 DMG，同时生成 SHA-256 文件；安装与数据恢复见 [安装与备份](macOS安装与备份.md)。

`--demo` 使用独立临时目录、两台虚构服务器和原创封面，禁止外部请求。关闭窗口或按 `⌘Q` 会退出应用、停止辅助进程并清理演示目录。演示中的设置修改和远端更新按钮不可用。

关闭演示后，双击 `.app` 或运行 `open dist/EmbyScope.app` 可进入正式模式。首次设置本地管理员密码，然后手动添加自己的连接。**正式模式添加连接会读取远端；演示模式不含真实账号。** 不要同时运行多个不同副本；相同配置目录有实例锁。

## 页面与数据含义

- **此刻**：顶部为最近有有效最后播放时间的条目；没有有效日期时可展示继续观看但不虚构时间。下方分别展示继续观看和最近观看清单。
- **概览**：第二页保留媒体计数、去重计数、来源状态、媒体库、最近入库和缓存时间。在线状态来自最近同步结果，不是持续探测。
- **片库**：全局服务器筛选、标题搜索、电影／电视剧筛选、每页 24 条。切换来源重置页码，返回页面保留当前结果。
- **同作品对照**：显示当前筛选范围内多条记录的作品；打开详情后对照范围是全部连接缓存，界面明确标出。记录数包含当前条目，当前记录置顶。记录不等于文件，不能据此判断文件可删除。
- **详情**：简介、年份、评分、类型、作品编号、分服务器条目标识和资源位置。位置按需读取并沿用后端权限与脱敏规则；资源路径可能属于容器、STRM 或虚拟目录。电视剧支持季筛选及单集分页。
- **服务器设置**：连接增删改、NSFW 标签、轻量和完整校准周期、自动更新总开关、手动更新、本地状态重读和锁定。所有远端访问仍由后端限速。

顶部眼睛按钮只改变本次会话的 NSFW 展示；每张虚化海报也可单独解除。切换来源、锁定或退出恢复遮挡。遮挡属于显示偏好，图片仍可能加载到内存。

最近观看读取本地 `catalog/latest/resume` 快照中的 `LastPlayedDate`，按时间排序，最多 24 条；一条媒体库记录只有最后一次时间，**不是完整观看历史、不代表已经看完，也不会从入库时间推导观看**。快照仅覆盖接口曾返回且仍在缓存里的条目。轻量更新无法补齐所有已看完且不再出现在继续观看中的作品。各来源缓存时间、离线和权限问题会保留提示。

## 保存、安全与更新

正式配置独立保存于 `~/Library/Application Support/EmbyScope/`，包含 `embyscope.sqlite` 与 `secret.key`。加密和备份边界与网页版一致：需要备份完整目录；拿到整个目录的人仍可能解密凭据。退出应用后再备份，不要只复制正在写入的单个 SQLite 文件。

不会自动迁移项目 `data/`，也不读取 TTD 凭据。本次按用户授权已将现有网页版数据一致性复制到独立桌面目录，并保留原目录及一份额外备份；导入后通过 `offline-preview` 标记强制离线。已有网页版继续使用自己的目录和端口。桌面监听仅为 `127.0.0.1` 的随机端口，每次启动通过匿名管道传入随机密钥，并保留管理员会话和请求来源检查；随机端口本身不承担认证。不会把启动密钥放入命令行、环境变量或日志。

自动更新默认关闭。切回窗口不会扫库或重新启动内核；界面保留内存中的当前数据。手动更新由后端执行，可点顶部「刷新本地快照」、按 `⌘R`，或点设置页「重新读取本地状态」查看进度和完成结果；当前没有持续轮询 UI。开启自动更新后内核可以同步，但界面仍需重读本地状态才能显示最新快照。关闭自动更新不等于断网：详情、未缓存海报、新连接初始化和手动操作仍可能读取远端。

动效仅为短暂入场、悬停和面板过渡，没有持续动画计时器；遵循系统减少动态效果，并提供应用内开关。海报使用懒加载和解码缩略图，内存图片缓存目标为 24 MiB、64 张；这不是整个应用的内存硬上限，当前显示的图片和 Node 查询也占内存。

已在本机验证独立运行、模拟两服、真实缓存导入、20 轮分页切页、来源筛选、资源对照、NSFW 和退出清理；DMG 已完成本机安装与内置备份恢复命令验证。经单独授权，在临时副本中验证了两台真实服务器的登录和轻量更新接口，未在原生界面开启在线模式或完整扫库。未进行整夜真实大库压力测试、验证 Intel Mac 或跨机器分发。具体数字和限制见 [验收记录](macOS验收记录.md)。
