# 实时会话与续播活动线索

**结论速览：**普通 Emby 读取当前用户 Sessions；极影视仅在用户启用兼容检测后，从连续续播变化报告“活动线索”，不报告确定在播或停止。
**适用条件：**映览 0.1.8–0.1.10；极影视真实字段变化只验证过 VidHub，其他客户端与新版 App 长期在线轮询仍待验收。

## ✅ 连续变化可以用于有边界的活动检测（2026-10-23）

- **环境：**macOS / Node 22.22.2 / SwiftUI；极影视 Emby 兼容服务与 VidHub，NAS 固件未采集。
- **为何值得记：**用户多轮配合播放、退出、暂停和恢复，已排除“有续播记录就是在播”的错误推断。
- **最终方案：**使用 [检测器](../../src/playback-activity.js) 与 [读取入口](../../src/playback.js)，参数原文如下；完整用户操作与语义在 [使用说明](../macOS使用说明.md) 的 0.1.8 节维护。

```js
export const ACTIVITY_INTERVAL = 15000
export const ACTIVITY_TTL = 60000
export const ACTIVITY_SNAPSHOT_TTL = 35000
const MAX_SAMPLE_GAP = 45000
```

- **为什么这样做：**至少三次样本产生两次合理位置前进且 LastPlayedDate 改变才建立活动；绝对播放日期存在约 8 小时表达异常，使用本机收样时刻判断新鲜度，不擅自修正 NAS 时间。暂停与退出都可能不再变化。
- **验证证据：**[原对照路线](../plans/极影视播放状态验证路线.md) 保存 21 次获授权采样摘要；[脱敏时间序列](../../test/fixtures/resume-activity.json) 随测试重放。[回归测试](../../test/playback-activity.test.js) 覆盖静态历史、拖动、倒退、缺失、失败、账号切换和跨服隔离；0.1.10 全部 74 项 Node 测试通过。
- **关键步骤：**确认当前用户身份 → 首次建立基线 → 连续采样 → 展示活动/观察中/未检测到活动/未知 → 离开前台停止新请求，重新进入重建观察轮次。
- **易错点：**60 秒活动保留与35秒快照过期是两个时钟；读取停止或失败后不能沿用“活动”冒充实时。Played 是完成标志；Resume 最多18条，空列表不证明全部停止。兼容模式不伪造设备和进度条。
- **交叉验证：**单 agent 真实取样记录、自动重放和原生模拟 UI，非多 agent 精粹；证据见上述路线与 [macOS 验收](../macOS验收记录.md) 0.1.8 节。

## 🔶 确定状态、其他播放器和长期在线运行（2026-10-23）

- **环境/交叉验证：**上述单一 NAS 与 VidHub；本轮仅文档复核。
- **当前推断：**其他播放器可能更新相同字段，但没有实测，不能宣传全客户端支持。明确在播/暂停/停止仍缺可读取的数据源。
- **已到哪一步：**TTD 看板与原 Emby Sessions 曾匹配同一账号同一条目；极影视受保护用户接口200、两种 Sessions路径404。单次标准根 WebSocket 请求头认证握手也404，未建立事件连接。
- **下一步验证动作：**新授权下对指定客户端进行未播放/播放/暂停/恢复/退出对照，或取得官方事件入口及认证依据后再定点检查；停止盲猜路径。
- **为何值得继续：**确定状态和活动线索是不同产品承诺，不能靠增加轮询频率弥补数据源缺失。

## ⛔ 将 TTD 取链记录、进度上报成功或 TimelineView 当成实时查询（2026-10-23）

- **环境/交叉验证：**TTD运行页面与用户容器日志、映览早期SwiftUI实现；单 agent，详见 [TTD记录](../TTD兼容排查.md)。
- **报错/观察原文：**`POST /emby/Sessions/Playing/Progress?reqformat=json HTTP/1.1` 返回 `204 0`；原界面已有 TimelineView 但仍只有手动快照。
- **稳定片段：**`/Sessions/Playing/Progress`、`204`、`GET /api/logs`。这些是访问日志材料，不是可直接执行的操作指令。
- **错误原因：**上报被HTTP层接受不证明存在可查询状态出口，日志缺请求正文和规则归属；日志页面轮询不是播放器心跳。TimelineView仅重算显示，不自动调用远端。
- **为何不可再采用：**TTD `/api/emby/live` 当时绑定原 Emby，不能把结果归给另一台极影视；一次取链也不能证明持续播放。
- **替代方案：**普通服务明确会话读取；极影视采用本页经用户接受的活动线索方案。不要因此插入新代理或改变正常302。
- **判定时效：**2026-10-23 已检查的运行接口；未来受支持的规则级状态接口可重新评估。
